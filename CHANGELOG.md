# Changelog

All notable ChatXPT changes are collected here by Role 1 from role-owned fragments under `changes/`.

The format follows Keep a Changelog categories: `Added`, `Changed`, `Fixed`, `Security`, `Deprecated`, and `Removed`. During the build challenge, unreleased work remains in fragments to avoid merge conflicts.

## Unreleased — 2026-08-03 foundation checkpoint

### Added

- Five-role authority, beginner-safe Git/Codex workflow, role guides, TODOs, CODEOWNERS, PR/issue templates, and change-fragment process ([#2](https://github.com/Dewflash/chatxpt/pull/2)).
- Concurrent implementation plans for Roles 1-3 with owner decision gates, evidence requirements, deadlines, and integration exits ([#4](https://github.com/Dewflash/chatxpt/pull/4)).
- Version `1.0.0` platform-neutral schemas, public ports, truthful provenance/unknown handling, typed commands/errors, valid/invalid fixtures, and contract tests ([#6](https://github.com/Dewflash/chatxpt/pull/6)).
- Collision-free public entrypoints for Roles 1-5 plus public-only consumer compatibility tests ([#7](https://github.com/Dewflash/chatxpt/pull/7)).
- Role 1 application orchestrator with injected authorization/persistence/projection ports, expected revisions, idempotency, authoritative event stamping, atomic fixture persistence before broadcast, and reconnectable committed state ([#8](https://github.com/Dewflash/chatxpt/pull/8)).
- TypeScript-AST ownership-boundary enforcement and a factual legacy migration inventory that leaves open owner decisions unresolved ([#9](https://github.com/Dewflash/chatxpt/pull/9)).
- Supabase persistence and private realtime foundation with revisioned authoritative state, lifecycle recovery, access grants, sanitised shared snapshots, browser/server adapters, and a production-shaped local fallback ([#12](https://github.com/Dewflash/chatxpt/pull/12)).

### Changed

- Granted Role 2 scoped authority to author the synchronised Role 4 and Role 5 build plans while preserving their source and detailed UX ownership ([#3](https://github.com/Dewflash/chatxpt/pull/3)).
- Made public seams, Role 1 orchestration, producer/consumer tests, revisioned realtime rules, tiered game capabilities, and integration after every wave binding team requirements ([#5](https://github.com/Dewflash/chatxpt/pull/5)).
- Compiled the foundation checkpoint, published one role-by-role pickup/open-decision/verification/reality handoff, and reconciled its merged coordination status ([#10](https://github.com/Dewflash/chatxpt/pull/10), [#11](https://github.com/Dewflash/chatxpt/pull/11)).

### Security

- Restricted authoritative persistence and snapshot publication to the server boundary, added expiring session-scoped realtime grants and private-channel policies, revoked direct client table access, and removed viewer-specific fields from shared broadcasts ([#12](https://github.com/Dewflash/chatxpt/pull/12)).

### Reality status

- The collaboration rules, contracts, entrypoints, boundary enforcement, fixture orchestrator behavior, Supabase adapters/migrations, local fallback, tests, and production build are implemented.
- Supabase cloud migration/RLS/private-WebSocket execution remains unclaimed until a shared project or Docker runtime is available. Twitch, OBS capture, Vercel, production AI/extraction, Role 3 mechanics, and Role 4/5 UI are also not claimed by this checkpoint.
